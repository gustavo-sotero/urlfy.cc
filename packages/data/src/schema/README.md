# Database Schema

## Purpose

Type-safe database schema definitions for Drizzle ORM. This is the single source of truth for database structure.

## Structure

- Domain-based files (e.g., `links.ts`, `auth.ts`, `analytics.ts`)
- Shared utilities and enums as needed
- Generated migration outputs are tracked under `packages/data/migrations/`
  (generated by `bun run db:generate` → Turborepo targets `@urlfy/data`)

## Patterns Used

- Drizzle table definitions with explicit column types
- Centralized indexes and constraints per table
- Avoid duplication of types outside schema files

## Adding New Files

1. Create a new schema file under this directory.
2. Export tables and enums from the root `schema.ts` aggregator.
3. Run migrations: `bun run db:generate` then `bun run db:migrate`.
